## ⭐ Projetos em destaque

### 🛒 Procurement Intelligence

Sistema de apoio à decisão de compras desenvolvido como case de **Procurement Analytics**.

O projeto combina equalização de cotações, histórico de preços, desempenho de fornecedores e um **Best Buy Score multicritério** para apoiar a escolha de compra além do menor preço.

**Competências:** Procurement Analytics · Python · Excel · KPIs · Supplier Performance · Decision Support

➡️ [Ver projeto](https://github.com/Ludmillags/procurement-intelligence)

### 📊 KPI Engenharia — Excel/VBA

Projeto em Excel habilitado para macros voltado à organização e acompanhamento de indicadores operacionais, demonstrando aplicação de **Excel e automação VBA** em rotinas de gestão.

**Competências:** Excel · VBA · KPIs · Automação · Análise operacional

➡️ [Ver projeto](https://github.com/Ludmillags/PlanFatHorasCompras)

### 💱 Cotação de Moedas em Python

Aplicação desktop que consulta cotações de Dólar, Euro e Bitcoin através de API e apresenta os dados em uma interface construída com Tkinter.

**Competências:** Python · APIs REST · JSON · Requests · Tkinter

➡️ [Ver projeto](https://github.com/Ludmillags/cotacaobolsa)
